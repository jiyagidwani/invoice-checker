Rulebook and approvals

Rules only change through an approved request with an official source. Approved changes are what the customer checker reads.

Propose a change

Nothing changes until an admin approves it. A change to tax rates needs a link to an official notice, and the person who proposes it cannot approve it.

Change requests

What counts as a source

Rule changes only come from official pages. A news story, a social post or a forwarded message can point you to something worth checking, but it cannot change a rule.

How a monitor would work in production

  1. A scheduled job opens only the allow-listed official pages (notifications, press releases, GST Council updates).
  2. It compares each page with the last copy it saw. Nothing new means nothing happens.
  3. For a real change, it drafts a change request with the link and the exact passage, and adds it to the queue as pending.
  4. An admin opens the source, confirms it says that, and approves or rejects. Nothing is ever applied automatically.

This prototype has no server, so the monitor is not built. Pages that block automated readers, scanned PDFs and changes in wording all mean a person has to read the notice.
